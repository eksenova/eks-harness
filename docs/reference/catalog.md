# Catalog reference

Generated by `eks-harness docs` from the built-in registry. Do not edit by hand; run `eks-harness docs --out docs/reference` instead.

The catalogs the edit, overlay, analysis and target models draw from. Every entry is a pydantic model
with a `kind`; plugins add entries with `@eks.effect`, `@eks.transition`, `@eks.easing`, `@eks.curve`,
`@eks.overlay_kind`, `@eks.marker` and `@eks.target_kind`.

## Effects

Per-clip video effects of an edit, applied in order after the clip's source frame and before its transform. Attach them with `clip.effect(...)`; most have a factory on `eks.fx`.
