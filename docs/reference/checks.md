# Check reference

Generated by `eks-harness docs` from the built-in registry. Do not edit by hand; run `eks-harness docs --out docs/reference` instead.

Every check kind the built-in registry knows, by family, with its parameters. Plugins add kinds with
`@eks.check(kind, family=...)`.

| Family | Kinds |
| --- | --- |
| [Checkpoint checks](#checkpoint-checks) | `broken_images`, `console_errors`, `error_toasts`, `failed_requests`, `horizontal_scroll`, `layout_spill`, `page_errors`, `route` |
| [Visual regression checks](#visual-regression-checks) | `visual` |
| [Performance checks](#performance-checks) | `perf`, `perf_rn` |
| [Media checks](#media-checks) | `beats`, `black`, `cut`, `frozen`, `loudness`, `motion`, `onset`, `safe_area`, `template`, `text` |

## Checkpoint checks

Run by `s.checkpoint(label)` (op `check.checkpoint`) on the session's screen. Checks marked default run on every checkpoint that has no `checks=` of its own; `checks=[eks.checks.use(kind, **params)]` picks others. A failed check fails the run unless the checkpoint is soft or the message matches the session's noise list.

## Visual regression checks

Golden comparisons at a checkpoint. Executors answer `check_unsupported` until the visual regression tooling lands.

### visual

Perceptual diff against the approved golden of this checkpoint and viewport.

| Property | Value |
| --- | --- |
| Family | `visual` |
| Model | `VisualGolden` |
| Platforms | android, ios, web |
| Default | no |

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `golden` | `str \| None` |  | `null` | Golden name; the checkpoint label and viewport when unset |
| `threshold` | `float` |  | `0.001` | Largest share of differing pixels that passes |
| `masks` | `list[Target]` |  | `[]` | Regions excluded from the diff |

## Media checks

Run by `check.media` on a rendered or captured media file. In an edit they are queued with `e.expect.<kind>(...)`, or derived from the timeline with `e.expect.derive(...)`.

| --- | --- |
| Family | `media` |
| Model | `BeatsCheck` |
| Platforms | any |

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |

### safe_area

Text and key content stay inside the platform safe area.

| Property | Value |
| --- | --- |
| Family | `media` |
| Model | `SafeAreaCheck` |
| Platforms | any |

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `margins` | `tuple[float, float, float, float]` |  | `[0.1, 0.05, 0.2, 0.05]` | Unsafe margins as fractions of the frame: top, right, bottom, left |
| `region` | `Target \| None` |  | `null` | Content that must stay inside; all text when unset |
| `engine` | `"auto" \| "vision" \| "tesseract"` |  | `"auto"` | OCR engine that finds the text (all text when region is unset): vision (macOS Vision) or tesseract, failing when it is unavailable; auto picks Vision on macOS and Tesseract elsewhere, so the result is keyed per machine |
