# Preset reference

Generated by `eks-harness docs` from the built-in registry. Do not edit by hand; run `eks-harness docs --out docs/reference` instead.

Named definitions that plans refer to by name. When a plan is built the name stays in the plan; the
engine resolves it to the value below when it runs the op. Plugins and projects add presets with
`@eks.preset(name, category=...)`.

| Category | Model | Presets |
| --- | --- | --- |
| [network](#network) | `NetProfile` | `3g`, `4g`, `offline`, `slow-3g`, `wifi` |
| [pace](#pace) | `Pace` | `demo` |
| [style](#style) | `OverlayStyle` | `kb`, `review` |
| [viewport](#viewport) | `Viewport` | `desktop`, `phone`, `tablet` |

## network

Named by `s.net.shape(profile)` (op `net.shape`).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `latency` | `Time` | required | Added round-trip latency |
| `down_kbps` | `int \| None` | `null` | Download bandwidth in kbit/s; unlimited when unset |
| `up_kbps` | `int \| None` | `null` | Upload bandwidth in kbit/s; unlimited when unset |
| `loss` | `float` | `0.0` | Share of dropped packets from 0 to 1 |
| `offline` | `bool` | `false` | No network at all |

### network: 3g

Fast 3G (Chrome): 563ms latency, 1440/675 kbps.

```json
{
  "down_kbps": 1440,
  "latency": "0.563s",
  "loss": 0.0,
  "offline": false,
  "up_kbps": 675
}
```

### network: 4g

4G: 60ms latency, 9000/9000 kbps.

```json
{
  "down_kbps": 9000,
  "latency": "0.06s",
  "loss": 0.0,
  "offline": false,
  "up_kbps": 9000
}
```

## pace

Named by `pace=` of `s.record(...)` and of the session; it sets how recordings move, dwell and type.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `move` | `Time` | required | Pointer travel time to a target |
| `dwell` | `Time` | required | Pause on a target before acting |
| `type_per_char` | `Time` | required | Time per typed character |
| `hold` | `Time` | required | Pause after an action |
| `screen_hold` | `Time` | required | Pause after a screen change |
| `press` | `Time` | required | Length of a press |

### pace: demo

Demo pacing: 300ms moves, 400ms dwell, 40ms per typed character.

```json
{
  "dwell": "0.4s",
  "hold": "0.7s",
  "move": "0.3s",
  "press": "0.25s",
  "screen_hold": "1.5s",
  "type_per_char": "0.04s"
}
```

## style

Named by `style=` of an overlay; it sets colours, fonts and sizes of the overlay renderers.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `ref_width` | `int` | required | Reference frame width in pixels; every pixel size of the style is scaled by the actual frame width divided by this |
| `fonts` | `StyleFonts` | required | Fonts used for overlay text |
| `colors` | `StyleColors` | required | Colors of each overlay element |
| `stroke` | `int` | required | Outline width of highlight boxes, in reference pixels |
| `halo` | `int` | required | Width of the white halo around badges and callout boxes, in reference pixels |
| `badge_shape` | `"circle" \| "rounded"` | `"circle"` | Shape of step badges: a circle or a rounded square |
| `badge_size` | `int` | required | Diameter (or side) of step badges, in reference pixels |
| `badge_font_size` | `int` | required | Font size of badge numbers, in reference pixels |
| `callout_font_size` | `int` | required | Font size of callout and arrow label text, in reference pixels |
| `callout_padding` | `int` | required | Inner padding of the callout box, in reference pixels |
| `callout_leader_width` | `int` | required | Width of the leader line from a callout to its target, in reference pixels |
| `callout_max_width` | `int` | required | Maximum callout box width before text wraps, in reference pixels |
| `arrow_width` | `int` | required | Line width of arrows, in reference pixels |
| `arrow_head` | `int` | required | Size of the arrow head, in reference pixels |
| `spotlight_dim` | `float` | required | Opacity of the dimming layer around a spotlight, from 0 (none) to 1 (opaque) |
| `caption_font_size` | `int` | required | Font size of caption text, in reference pixels |
| `caption_bar_height` | `int` | required | Height of the caption bar, in reference pixels |
| `title_font_size` | `int` | required | Font size of title card titles, in reference pixels |
| `title_sub_font_size` | `int` | required | Font size of title card subtitles, in reference pixels |

## viewport

Named by `viewport=` of a flow, a checkpoint, a shot or a recording. A viewport of the app profile with the same name wins.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `width` | `int` | required | Width in CSS pixels |
| `height` | `int` | required | Height in CSS pixels |
| `scale` | `float` | `1.0` | Device pixel ratio |
| `mobile` | `bool` | `false` | Emulate a mobile browser (meta viewport, mobile user agent) |
| `touch` | `bool` | `false` | Emulate a touch screen |

### viewport: desktop

1920x1080 desktop browser.

```json
{
  "height": 1080,
  "mobile": false,
  "scale": 1.0,
  "touch": false,
  "width": 1920
}
```

### viewport: phone

390x844 phone at 3x with touch.

```json
{
  "height": 844,
  "mobile": true,
  "scale": 3.0,
  "touch": true,
  "width": 390
}
```

### viewport: tablet

820x1180 tablet at 2x with touch.

```json
{
  "height": 1180,
  "mobile": true,
  "scale": 2.0,
  "touch": true,
  "width": 820
}
```
