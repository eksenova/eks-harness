# Cookbook

Complete, working examples of the eks API, grouped by the three example trees in `examples/`. Each entry says
what the example shows and how to run it, and quotes its source. The op, catalog and check names used here are
documented in [reference/](reference/).

| Tree | What it holds | How it runs |
| --- | --- | --- |
| [`examples/cookbook`](#cookbook-edits-and-gfx-scenes) | 18 video edits and 2 gfx scenes on generated fixtures | renders on a hub; every edit renders byte-identical twice |
| [`examples/reference`](#reference-apps-flows-and-seeds) | a web app, a native Android app, an Expo iOS app, a backend with seed hooks, flows and seeds | runs on a hub with a real browser, simulator and emulator |
| [`examples/dsl`](#design-examples) | one example per section of the design: flows, seeds, edits, scenes, a score and a plugin | plans and validates (`eks-harness plan`); the apps and backend it names are not part of the tree |

Every command below runs from the tree's folder (`cd examples/cookbook` and so on), against a running hub
(`eks-harness daemon start`).

## Cookbook: edits and gfx scenes

The cookbook renders its edits from fixtures generated by `.harness/assets/generate.py`: test-pattern videos from
ffmpeg's `lavfi` sources, a synthetic 120 bpm beat (`music.wav`), a 140 bpm drop (`drop.wav`), a voice-like track
(`vo.wav`), photos, a sticker, a logo, a LUT, and two talking clips with that voice (`interview.mp4`, `talk.mp4`).
Everything is written with bitexact flags, so the fixtures have the same bytes on every machine with the same
ffmpeg; the generated files are gitignored.

```bash
cd examples/cookbook
uv run python .harness/assets/generate.py        # needs ffmpeg; prints the SHA-256 of every fixture
eks-harness plan .harness/edits/titles.py        # build and validate without rendering
eks-harness run .harness/edits/titles.py         # render on the hub; the report links the MP4
eks-harness run .harness/edits/titles.py --cache off --repeat 2   # render twice and compare
```

Edits render with the `video` extra (`eks-harness[video]`: skia-python, numpy, librosa and the rest). Six recipes
run an analysis that needs a package outside it; without the package the node fails with
`resolution_unavailable` naming it:

| Recipe | Needs |
| --- | --- |
| `auto_reframe_vertical` | `mediapipe` (face tracking) |
| `captioned_tutorial`, `talking_head_meme` | `faster-whisper` (speech to text) |
| `chapter_markers_youtube` | `scenedetect` (scene cuts) |
| `sponsor_skipper`, `multicam_switching` | `librosa` (silence and onset markers; part of the `video` extra) |

`faster-whisper` and `mediapipe` are in the `ml` extra; `scenedetect` is installed on its own
(`uv pip install scenedetect`, or `uv tool install ... --with scenedetect`). Every edit sets
`render_settings(encoder="libx264", quality="draft", threads=4)`, the software encoder that keeps the output
byte-identical, and calls `e.expect.derive(...)` so the run also checks its own cuts, captions, beats and loudness.

`tests/media/test_cookbook.py` renders a fast subset twice with the cache off and compares SHA-256 digests; with
`EKS_COOKBOOK_FULL=1` it renders all 18.

`examples/cookbook/.harness/project.toml`:

```toml
[project]
id = "examples/cookbook"
```

### annotated_walkthrough

Video overlays on a recording: a title, a callout, a highlight, an arrow from a point to a rectangle, a redaction over the whole clip, a step badge and a caption, each with its own time window. Anchors are `by.rect` and `by.point` in frame coordinates, since a generated clip has no box map. The derived checks OCR the title and caption text.

```bash
eks-harness run .harness/edits/annotated_walkthrough.py
```

`examples/cookbook/.harness/edits/annotated_walkthrough.py`:

```python
import eks
from eks import by, t


@eks.edit(fps=30, size=(1080, 1920), seed=37, duration=t("6s"))
def annotated_walkthrough(e: eks.Edit):
    e.render_settings(encoder="libx264", quality="draft", threads=4)
    e.track("main").clip(e.media("../assets/main_clip.mp4"), start=t("0s"), src=t.span(t("0s"), t("6s")))
    e.track("notes", z=1).overlay(
        eks.overlay.title("Yeni fatura", subtitle="Kontör işlemleri", at=t.span(t("0s"), t("1500ms"))),
        eks.overlay.callout(by.rect(120, 600, 840, 220), "Anlık kur", at=t.span(t("1500ms"), t("3s"))),
        eks.overlay.highlight(by.rect(120, 900, 840, 160), at=t.span(t("3s"), t("4500ms"))),
        eks.overlay.arrow(by.point(540, 1500), to=by.rect(120, 900, 840, 160), text="Kaydet",
                          at=t.span(t("3s"), t("4500ms"))),
        eks.overlay.redact(by.rect(120, 1700, 840, 120), at=t.span(t("0s"), t("6s"))),
        eks.overlay.step(by.point(540, 400), 1, at=t.span(t("4500ms"), t("6s"))),
        eks.overlay.caption("Faturayı kaydedin", at=t.span(t("4500ms"), t("6s"))),
    )
    e.expect.derive(beats=False, loudness=False)
```

### beat_flash_montage

Clips placed on the beat grid of the music (`start=t("beat:N")`), joined with `beat_flash` transitions, and a last clip that flashes on downbeats 4 and 5 (`t.beats("downbeat")[4:6]`). `.beats("beat", "downbeat")` on the music track makes its beat analysis the clock's tempo source, so the derived `beats` check verifies the cuts land on beats.

```bash
eks-harness run .harness/edits/beat_flash_montage.py
```

`examples/cookbook/.harness/edits/beat_flash_montage.py`:

```python
import eks
from eks import t


@eks.edit(fps=30, size=(720, 1280), seed=11)
def beat_flash_montage(e: eks.Edit):
    e.render_settings(encoder="libx264", quality="draft", threads=4)
    e.audio.track("../assets/music.wav", name="music", gain=-6).beats("beat", "downbeat")
    main = e.track("main")
    clips = [e.media(f"../assets/clip_{index}.mp4") for index in range(4)]
    for index, clip in enumerate(clips):
        piece = main.clip(clip, start=t(f"beat:{index * 4}"), src=t.span(t("0s"), t("2s")))
        if index:
            piece.transition_in(eks.tx.beat_flash(t("8f"), stream="beat"))
    main.clip(clips[0], start=t("beat:16"), src=t.span(t("2s"), t("3s"))).effect(
        eks.fx.flash(t.beats("downbeat")[4:6], t("3f")))
    e.expect.derive()
```

### captioned_tutorial

Speech to text with `eks.media.markers(recording, eks.media.STTMarkers(...))`, then burned-in captions from that stream (`eks.fx.captions("speech")`) and a slow `punch_in`. Needs `faster-whisper`.


`examples/cookbook/.harness/edits/captioned_tutorial.py`:

```python
import eks
from eks import t


@eks.edit(fps=30, size=(1280, 720), seed=47)
def captioned_tutorial(e: eks.Edit):
    e.render_settings(encoder="libx264", quality="draft", threads=4)
    recording = e.media("../assets/talk.mp4")
    eks.media.markers(recording, eks.media.STTMarkers(name="speech", language="tr", model="small", device="cpu",

    e.expect.derive(beats=False)
```

### lyric_video

Words on the bar grid (`t("bar:N")` to three beats later) over a slowed background (`speed=0.75`) whose brightness flickers with a seeded `noise` curve and flashes on downbeats.

```bash
eks-harness run .harness/edits/lyric_video.py
```

`examples/cookbook/.harness/edits/lyric_video.py`:

```python
import eks
from eks import t


@eks.edit(fps=30, size=(720, 1280), seed=21, duration=t("8s"))
def lyric_video(e: eks.Edit):
    e.render_settings(encoder="libx264", quality="draft", threads=4)
    e.audio.track("../assets/music.wav", name="song", gain=-4).beats("beat", "downbeat")
    background = e.media("../assets/clip_2.mp4")
    main = e.track("main")
    main.clip(background, start=t("0s"), src=t.span(t("0s"), t("6s")), speed=0.75).effect(
        eks.fx.brightness(eks.curves.noise(min_value=-0.08, max_value=0.08, hold=t("250ms"))),
        eks.fx.flash(t.beats("downbeat")[0:8], t("2f")))
    words = e.track("words", z=1)
    lines = ["Kuyumcular", "için", "tek", "ekran"]
    for index, word in enumerate(lines):
        words.overlay(eks.overlay.caption(word, at=t.span(t(f"bar:{index}"), t(f"bar:{index}") + t("3b"))))
    e.expect.derive(cuts=False, loudness=False)
```

### mix_only

An audio-only edit: music panned left and ducked under a compressed voice-over, mastered to -14 LUFS with a -1 dBTP ceiling, and a `loudness` check on the result.

```bash
eks-harness run .harness/edits/mix_only.py
```

`examples/cookbook/.harness/edits/mix_only.py`:

```python
import eks
from eks import t


@eks.edit(fps=30, size=(640, 360), seed=41, duration=t("10s"), background="#0d1b2a")
def mix_only(e: eks.Edit):
    e.render_settings(encoder="libx264", quality="draft", threads=4)
    music = e.audio.track("../assets/music.wav", name="music", gain=-4, pan=-0.2)
    voice = e.audio.track("../assets/vo.wav", name="voice", start=t("1s"), pan=0.1)
    music.duck("voice", amount_db=-10)
    voice.compress(threshold_db=-20, ratio=3, attack=t("10ms"), release=t("120ms"), makeup_db=2)
    e.audio.master(loudness=-14, true_peak=-1)
    e.expect.loudness(-14, true_peak=-1)
```

### multicam_switching

Onset analysis of the audio (`OnsetMarkers(name="hits")`) picks the cut points: every third hit switches to the next camera.

```bash
eks-harness run .harness/edits/multicam_switching.py
```

`examples/cookbook/.harness/edits/multicam_switching.py`:

```python
import eks
from eks import t


@eks.edit(fps=30, size=(1280, 720), seed=67, duration=t("10s"))
def multicam_switching(e: eks.Edit):
    e.render_settings(encoder="libx264", quality="draft", threads=4)
    mic = e.audio.track("../assets/music.wav", name="floor", gain=-6)
    mic.markers(eks.media.OnsetMarkers(name="hits", sensitivity=0.6))
    cams = [e.media(f"../assets/clip_{index}.mp4") for index in range(3)]
    main = e.track("main")
    main.clip(cams[0], start=t("0s"), src=t.span(t("0s"), t("6s")))

        main.clip(cams[index % 3], start=t(f"marker:hits#{index * 3}"), src=t.span(t("0s"), t("6s")))
    e.expect.derive(beats=False)
```

### podcast_clip

A gfx scene used as a clip (`e.gfx("podcast_card")`), with an RGB split animated by keyframes and a brightness pulse on downbeats (`curves.beat_pulse` with an exponential decay envelope), a title overlay, music under a voice track, and a -16 LUFS master.

```bash
eks-harness run .harness/edits/podcast_clip.py
```

`examples/cookbook/.harness/edits/podcast_clip.py`:

```python
import eks
from eks import t


@eks.edit(fps=30, size=(720, 1280), seed=29, duration=t("8s"))
def podcast_clip(e: eks.Edit):
    e.render_settings(encoder="libx264", quality="draft", threads=4)
    e.audio.track("../assets/music.wav", name="music", gain=-14).beats("beat", "downbeat")
    e.audio.track("../assets/vo.wav", name="voice", gain=-2)
    card = e.gfx("podcast_card")
    e.track("card").clip(card, start=t("0s")).effect(
        eks.fx.rgb_split(eks.keys({t("0s"): 0, t("2s"): 8, t("4s"): 0})),
        eks.fx.brightness(eks.curves.beat_pulse(t.beats("downbeat")[0:4], eks.curves.exp_decay_env(t("120ms")),
                                                intensity=0.15)))
    e.track("titles", z=1).overlay(eks.overlay.title("Bölüm 42", subtitle="Kuyumculukta dijital kasa",
                                                     at=t.span(t("500ms"), t("3s"))))
    e.audio.master(loudness=-16, true_peak=-1)
    e.expect.derive(cuts=False)
```

### product_showcase

A photo slideshow: each photo zooms with `in_out_sine` easing, gets a LUT colour grade, every second one is mirrored, and photos crossfade; the music bed fades in and out.

```bash
eks-harness run .harness/edits/product_showcase.py
```

`examples/cookbook/.harness/edits/product_showcase.py`:

```python
import eks
from eks import t


@eks.edit(fps=30, size=(720, 1280), seed=5, duration=t("8.5s"))
def product_showcase(e: eks.Edit):
    e.render_settings(encoder="libx264", quality="draft", threads=4)
    e.audio.track("../assets/music.wav", name="bed", gain=-10).fade(fade_in=t("300ms"), fade_out=t("800ms"))
    main = e.track("main")
    for index in range(4):
        photo = e.media(f"../assets/photo_{index}.png")
        clip = main.clip(photo, start=t(f"{index * 2}s"), src=t.span(t("0s"), t("2.5s")))
        clip.effect(eks.fx.zoom(1.0, 1.15, ease="in_out_sine"), eks.fx.color_grade(lut="../assets/warm_filmic.cube"))
        if index % 2:
            clip.effect(eks.fx.mirror("horizontal"))
        if index:
            clip.transition_in(eks.tx.crossfade(t("500ms")))
    e.audio.master(loudness=-16, true_peak=-1.5)
    e.expect.derive(beats=False)
```

### slideshow_kenburns

`examples/cookbook/.harness/edits/slideshow_kenburns.py`:

```python
import eks
from eks import keys, t


@eks.edit(fps=30, size=(1280, 720), seed=13)
def slideshow_kenburns(e: eks.Edit):
    e.render_settings(encoder="libx264", quality="draft", threads=4)
    e.audio.track("../assets/music.wav", name="bed", gain=-12)
    main = e.track("main")
    transitions = [eks.tx.crossfade(t("600ms")), eks.tx.dip_to_black(t("600ms")), eks.tx.luma_wipe(t("600ms"))]
    for index in range(4):

        if index:
            clip.transition_in(transitions[index - 1])
    main.clip(e.media("../assets/photo_0.png"), start=t("10.5s"), src=t.span(t("0s"), t("1.5s"))).transition_out(
        eks.tx.dip_to_black(t("500ms")))
```


## Reference apps, flows and seeds

The reference tree holds three small apps, a backend and the flows that exercise every driver path on real
devices. Its plugin `reference` (trusted in `.harness/project.toml`) holds the app runtimes, the two backends and
the seed resource kinds.

| Path | What it is |
| --- | --- |
| `web-app/` | Vite and React app (invoices list, form, dialog, rates), served by its dev server on port 5391 |
| `android-app/` | native Kotlin app with no harness bridge; driven on the native surface |
| `ios-app/` | Expo React Native app with the harness bridge; its config plugin `plugins/with-scene-lifecycle.js` adopts the UIScene life cycle iOS 27 requires |
| `backend/server.py` | a JSON API over SQLite with admin routes for reset, snapshot, restore and migrations, plus an `infra` mode that serves the shared audit store |

`gradlew assembleDebug` when the APK is missing); for iOS, build the Expo app for the simulator into
`ios-app/ios/build/Build/Products/Debug-iphonesimulator/Referans.app` (the runtime installs it and starts Metro on

### Plugin module: app runtimes

Three `@eks.app` runtimes. The web runtime starts Vite with `ctx.spawn(..., ready_url=...)`; the Android runtime builds and installs the APK, resets the camera permission and launches the activity in `boot`; the iOS runtime installs the built app, points it at Metro, starts Metro with the worker URL in its environment and waits until the bridge answers `mobile.idle`.

`examples/reference/.harness/plugins/reference/reference_apps.py`:

```python
from __future__ import annotations

import os
import subprocess
import time
from collections.abc import Sequence
from pathlib import Path

import eks
from eks_harness.drivers.runtime import AppContext, AppRuntime, AppRuntimeError, RuntimeWorker
from eks_harness.pools.devices import tool

ROOT = Path(__file__).resolve().parents[3]
PACKAGE = "com.eksenova.reference"
ACTIVITY = f"{PACKAGE}/.MainActivity"
BUNDLE = "com.eksenova.reference"
APK = ROOT / "android-app" / "app" / "build" / "outputs" / "apk" / "debug" / "app-debug.apk"
IOS_APP = ROOT / "ios-app" / "ios" / "build" / "Build" / "Products" / "Debug-iphonesimulator" / "Referans.app"
METRO_PORT = 8181
BRIDGE_WAIT = 180.0


def run(argv: Sequence[str], *, cwd: Path | None = None, timeout: float = 120, env: dict[str, str] | None = None) -> str:
    done = subprocess.run(list(argv), cwd=cwd, capture_output=True, text=True, timeout=timeout, check=False,
                          env={**os.environ, **(env or {})})
    if done.returncode != 0:
        raise AppRuntimeError(f"{' '.join(argv[:4])} failed ({done.returncode}): {(done.stdout + done.stderr)[-600:]}")
    return done.stdout


def java_home() -> str:
    found = run(["/usr/libexec/java_home", "-v", "17"]).strip()
    if not found:
        raise AppRuntimeError("the Android build needs JDK 17")
    return found


@eks.app("reference-web", description="Vite and React reference app served by its dev server")
class ReferenceWeb:
    def prepare(self, ctx: AppContext) -> AppRuntime:
        port = int((ctx.profile.get("web") or {}).get("dev_port") or 5391)
        url = f"http://127.0.0.1:{port}"
        ctx.spawn(["npx", "vite", "--host", "127.0.0.1", "--port", str(port), "--strictPort"], key=f"reference-web-{port}",
                  cwd=ROOT / "web-app", ready_url=f"{url}/", timeout=120)
        return AppRuntime(url=url)


@eks.app("reference-android", description="Native Android reference app driven on the native surface")
class ReferenceAndroid:
    def _adb(self, ctx: AppContext, *args: str, timeout: float = 120) -> str:
        adb = tool("adb")
        serial = ctx.device.get("serial")
        if not adb or not serial:
            raise AppRuntimeError("the Android reference app needs adb and the emulator serial of the lease")
        return run([adb, "-s", str(serial), *args], timeout=timeout)

    def prepare(self, ctx: AppContext) -> AppRuntime:
        if not APK.is_file():
            run([str(ROOT / "android-app" / "gradlew"), "--no-daemon", "-q", "assembleDebug"], cwd=ROOT / "android-app",
                timeout=1800, env={"JAVA_HOME": java_home()})
        self._adb(ctx, "install", "-r", str(APK), timeout=300)
        self._adb(ctx, "shell", "am", "force-stop", PACKAGE)
        self._adb(ctx, "shell", "pm", "revoke", PACKAGE, "android.permission.CAMERA")
        self._adb(ctx, "shell", "pm", "clear-permission-flags", PACKAGE, "android.permission.CAMERA", "user-set",
                  "user-fixed")
        return AppRuntime()

    def boot(self, ctx: AppContext, worker: RuntimeWorker) -> None:
        self._adb(ctx, "shell", "am", "start", "-W", "-n", ACTIVITY)


@eks.app("reference-ios", description="Expo React Native reference app with the harness bridge")
class ReferenceIos:
    def _simctl(self, *args: str, timeout: float = 120) -> str:
        return run(["xcrun", "simctl", *args], timeout=timeout)

    def prepare(self, ctx: AppContext) -> AppRuntime:
        udid = str(ctx.device.get("udid") or "")
        if not udid:
            raise AppRuntimeError("the iOS reference app needs the simulator udid of the lease")
        if not IOS_APP.is_dir():
            raise AppRuntimeError(f"build the iOS reference app first; {IOS_APP} is missing")
        subprocess.run(["xcrun", "simctl", "terminate", udid, BUNDLE], capture_output=True, check=False, timeout=60)
        if ctx.native is not None:
            ctx.native.dismiss_alerts()
        self._simctl("install", udid, str(IOS_APP), timeout=300)
        self._simctl("privacy", udid, "reset", "location", BUNDLE)
        self._simctl("spawn", udid, "defaults", "write", BUNDLE, "RCT_jsLocation", f"127.0.0.1:{METRO_PORT}")
        return AppRuntime()

    def boot(self, ctx: AppContext, worker: RuntimeWorker) -> None:
        udid = str(ctx.device.get("udid"))
        ctx.spawn(["npx", "expo", "start", "--port", str(METRO_PORT)], key=f"reference-ios-metro-{METRO_PORT}",
                  cwd=ROOT / "ios-app", env={"CI": "1", "EXPO_PUBLIC_EHX_HARNESS_URL": worker.url},
                  ready_url=f"http://127.0.0.1:{METRO_PORT}/status", timeout=180)
        self._simctl("launch", "--terminate-running-process", udid, BUNDLE)
        deadline = time.monotonic() + BRIDGE_WAIT
        last: Exception | None = None
        while time.monotonic() < deadline:
            try:
                worker.call("mobile.idle", {"timeout": 5000}, timeout=30)
                return
            except Exception as error:
                last = error
                time.sleep(2)
        raise AppRuntimeError(f"the iOS reference app did not connect its harness bridge within {BRIDGE_WAIT:.0f} s: {last}")
```

### Plugin module: backends and resource kinds

`reference-infra` is a global backend (one instance for every tree) with a 20 second idle timeout. `reference-api` requires it, reads its URL from `context["dependencies"]`, and implements every seed hook (`migrations`, `reset`, `seed_phase`, `snapshot`, `restore`, `drop_snapshot`) through the server's admin routes. The resource kinds show each phase, a persona kind (`user`, whose output carries a token), keyless kinds with positional fields, a reference field resolved with `ctx.resolve`, and generated ids (`ctx.ids.vkn()`, `iban()`, `ulid()`, `uuid()`, `email()`).

`examples/reference/.harness/plugins/reference/reference_backend.py`:

```python
from __future__ import annotations

import hashlib
import json
import sys
import urllib.error
import urllib.request
from collections.abc import Mapping
from pathlib import Path
from typing import Annotated, Any

import eks
from eks import t
from eks_harness.plugins.sdk import (
    BackendInfo,
    BackendSpec,
    Health,
    ProcessSpec,
    Secret,
)

ROOT = Path(__file__).resolve().parents[3]
SERVER = ROOT / "backend" / "server.py"
ADMIN_KEY = "reference-admin"


def server_digest() -> str:
    return hashlib.sha256(SERVER.read_bytes()).hexdigest()[:16]


def state_dir(context: Mapping[str, Any], name: str) -> Path:
    path = Path(str(context["stateDir"])) / name
    path.mkdir(parents=True, exist_ok=True)
    return path


def admin(context: Mapping[str, Any], method: str, path: str) -> dict[str, Any]:
    port = int(context["ports"]["api"])
    request = urllib.request.Request(f"http://127.0.0.1:{port}{path}", method=method,
                                     headers={"X-Admin-Key": ADMIN_KEY})
    try:
        with urllib.request.urlopen(request, timeout=60) as response:
            body = response.read()
    except urllib.error.HTTPError as error:
        raise RuntimeError(f"{method} {path} answered {error.code}: {error.read().decode()[:300]}") from error
    return json.loads(body) if body else {}


@eks.backend("reference-infra", identity="global", idle_timeout=t("20s"),
             description="Shared audit store the reference API writes to; one instance for every tree")
class ReferenceInfra:
    def describe(self) -> dict[str, Any]:
        return {"description": "reference audit store", "ports": ["store"]}

    def fingerprint(self, context: Mapping[str, Any]) -> str:
        return server_digest()

    def prepare(self, context: Mapping[str, Any]) -> None:
        return None

    def spec(self, context: Mapping[str, Any]) -> BackendSpec:
        port = int(context["ports"]["store"])
        url = f"http://127.0.0.1:{port}"
        return BackendSpec(
            processes=[ProcessSpec(name="store", port="store",
                                   command=[sys.executable, str(SERVER), "infra", "--port", str(port), "--data",
                                            str(state_dir(context, "infra"))],
                                   health=Health(url=f"{url}/health", timeout=30))],
            info=BackendInfo(url=url, urls={"store": url}, version="1"))

    def teardown(self, context: Mapping[str, Any], final: bool = False) -> None:
        return None


@eks.backend("reference-api", requires=["reference-infra"],
             description="Reference JSON API over SQLite with seed snapshots")
class ReferenceApi:
    def describe(self) -> dict[str, Any]:
        return {"description": "reference API", "ports": ["api"]}

    def fingerprint(self, context: Mapping[str, Any]) -> str:
        return server_digest()

    def prepare(self, context: Mapping[str, Any]) -> None:
        if "reference-infra" not in (context.get("dependencies") or {}):
            raise RuntimeError("reference-api starts only with its reference-infra dependency")

    def spec(self, context: Mapping[str, Any]) -> BackendSpec:
        port = int(context["ports"]["api"])
        url = f"http://127.0.0.1:{port}"
        infra = context["dependencies"]["reference-infra"]["url"]
        return BackendSpec(
            processes=[ProcessSpec(name="api", port="api",
                                   command=[sys.executable, str(SERVER), "api", "--port", str(port), "--data",
                                            str(state_dir(context, "api")), "--admin-key", ADMIN_KEY,
                                            "--infra", infra],
                                   health=Health(url=f"{url}/health", timeout=30))],
            info=BackendInfo(url=url, urls={"api": url}, version="1", commit=server_digest(),
                             credentials={"admin": {"headers": {"X-Admin-Key": Secret(ADMIN_KEY)}}},
                             extra={"infra": infra}))

    def teardown(self, context: Mapping[str, Any], final: bool = False) -> None:
        return None

    def migrations(self, context: Mapping[str, Any]) -> str:
        return str(admin(context, "GET", "/admin/migrations")["migrations"])

    def reset(self, context: Mapping[str, Any]) -> dict[str, Any]:
        return admin(context, "POST", "/admin/reset")

    def seed_phase(self, context: Mapping[str, Any], phase: str) -> dict[str, Any]:
        return {"phase": phase}

    def snapshot(self, context: Mapping[str, Any], name: str) -> dict[str, Any]:
        return admin(context, "POST", f"/admin/snapshot?name={name}")

    def restore(self, context: Mapping[str, Any], name: str) -> dict[str, Any]:
        return admin(context, "POST", f"/admin/restore?name={name}")

    def drop_snapshot(self, context: Mapping[str, Any], name: str) -> dict[str, Any]:
        return admin(context, "DELETE", f"/admin/snapshot?name={name}")


@eks.resource("setting", phase="schema", description="A server setting written before any data")
class Setting(eks.Resource):
    value: str

    def create(self, ctx: Any) -> dict[str, Any]:
        ctx.api.put("/api/settings", json={"name": ctx.key, "value": self.value}, as_="admin")
        return {"name": ctx.key, "value": self.value}


@eks.resource("account", description="A company account with a generated tax number")
class Account(eks.Resource):
    name: str

    def create(self, ctx: Any) -> dict[str, Any]:
        parent = ctx.parent or {}
        body = {"name": self.name, "kind": "branch" if parent else "company", "taxNumber": ctx.ids.vkn(),
                "parentId": parent.get("id"), "createdAt": ctx.now.isoformat()}
        return dict(ctx.api.post("/api/accounts", json=body))


@eks.resource("branch", parent="account", description="A branch account under a company")
class Branch(eks.Resource):
    name: str

    def create(self, ctx: Any) -> dict[str, Any]:
        body = {"name": self.name, "kind": "branch", "taxNumber": ctx.ids.vkn(), "parentId": ctx.parent["id"],
                "createdAt": ctx.now.isoformat()}
        return dict(ctx.api.post("/api/accounts", json=body))


@eks.resource("user", parent="account", persona=True, description="A user of an account; a seed persona")
class User(eks.Resource):
    role: str = "admin"

    def create(self, ctx: Any) -> dict[str, Any]:
        token = ctx.ids.uuid()
        email = ctx.ids.email(local=ctx.key)
        created = ctx.api.post("/api/users", json={"accountId": ctx.parent["id"], "email": email,
                                                    "role": self.role, "token": token})
        return {"id": created["id"], "email": email, "role": self.role, "token": token, "persona": ctx.key,
                "account": ctx.parent["id"], "label": f"{ctx.key} ({self.role})"}


@eks.resource("payment", parent="account", keyed=False, positional=("amount",), phase="finalize",
              description="A payment into an account, made by one of its users")
class Payment(eks.Resource):
    amount: int
    payer: Annotated[eks.ResourceRef, eks.refers_to("user")]

    def create(self, ctx: Any) -> dict[str, Any]:
        payer = ctx.resolve(self.payer)
        body = {"accountId": ctx.parent["id"], "amount": self.amount, "iban": ctx.ids.iban(),
                "reference": ctx.ids.ulid(), "paidAt": ctx.now.isoformat()}
        created = ctx.api.post("/api/payments", json=body, as_=payer["persona"])
        return {"id": created["id"], **body}


@eks.resource("note", parent="account", keyed=False, positional=("text",), phase="mongo",
              description="A note kept outside the database, replayed after every restore")
class Note(eks.Resource):
    text: str

    def create(self, ctx: Any) -> dict[str, Any]:
        return dict(ctx.api.post("/api/notes", json={"accountId": ctx.parent["id"], "text": self.text}))
```

### control: control flow

`eks.when` and `eks.otherwise` on a run-time read, `eks.each` over the first three items of an API response, `eks.parallel` for independent lanes, and an `@eks.dynamic` function that runs on the hub with the real row count and returns one tap per row.

`examples/dsl/.harness/flows/control.py`:

```python
import eks
from eks import by


@eks.flow(app="web-app", seed="standard")
def control(s: eks.Session):
    with eks.when(s.ui.exists("#empty-state")):
        s.ui.tap("#create")
    with eks.otherwise():
        s.ui.tap(by.test_id("row").first)

    with eks.each(s.api.get("/api/invoices").items[:3]) as inv:
        s.ui.nav(f"/tenant/invoice/{inv.id}")
        s.checkpoint(f"fatura-{inv.number}")

    with eks.parallel():
        s.ui.nav("/tenant/invoice/list")
        s.api.get("/api/invoices")

    rows = s.ui.count("#row")

    @eks.dynamic
    def per_row(n=rows):
        return [s.ui.tap(by.test_id("row").nth(i)) for i in range(n)]
```

```python
from eks.audio import EqBand


@eks.edit(fps=30, size=(1080, 1920), seed=7)
def mix(e: eks.Edit):
```

```python
def _luminance(color: str) -> float:
    channels = [int(color.lstrip("#")[index:index + 2], 16) / 255 for index in (0, 2, 4)]
    linear = [value / 12.92 if value <= 0.03928 else ((value + 0.055) / 1.055) ** 2.4 for value in channels]
    return 0.2126 * linear[0] + 0.7152 * linear[1] + 0.0722 * linear[2]


def low_contrast(args: Contrast, texts: Sequence[tuple[str, str, str]]) -> list[str]:
    failing: list[str] = []
    for label, foreground, background in texts:
        lighter, darker = sorted((_luminance(foreground), _luminance(background)), reverse=True)
        if (lighter + 0.05) / (darker + 0.05) < args.minimum:
            failing.append(label)
    return failing

def locate_chips(tree: Mapping[str, Any], label: str) -> list[tuple[int, int, int, int]]:
    boxes: list[tuple[int, int, int, int]] = []

        if node.get("role") in ("button", "option", "checkbox") and node.get("name") == label:

            boxes.append((int(x), int(y), int(width), int(height)))

    return boxes

@eks.backend("eksenapi", description="The API built from the tree, started locally on a database restored from the seed")
class LocalApi:
    project = Path("src") / "api"

    def describe(self) -> dict[str, Any]:
        return {"name": "eksenapi", "project": self.project.as_posix(), "seeded": True}

    def fingerprint(self, context: Mapping[str, Any]) -> str:
        root = Path(str(context["tree"]))
        digest = hashlib.sha256()
        for source in sorted((root / self.project).rglob("*.cs")):
            digest.update(source.relative_to(root).as_posix().encode())
            digest.update(source.read_bytes())
        return digest.hexdigest()

    def prepare(self, context: Mapping[str, Any]) -> None:
        project = Path(str(context["tree"])) / self.project
        if not project.is_dir():
            raise FileNotFoundError(f"the tree has no API project at {project}")

    def spec(self, context: Mapping[str, Any]) -> BackendSpec:
        root = Path(str(context["tree"]))
        process = ProcessSpec(name="api", command=["dotnet", "run", "--project", self.project.as_posix()],
                              port="http", cwd=str(root), env={"ASPNETCORE_ENVIRONMENT": "Development"})
        return BackendSpec(processes=[process])

    def teardown(self, context: Mapping[str, Any], final: bool = False) -> None:
        return None
```
