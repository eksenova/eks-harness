---
description: Render an eks-harness video project or score
argument-hint: "[args]"
---

Load eks-harness:video-editing and eks-harness:scores. If $ARGUMENTS is a score (score.py or score.json) run `eks-harness score plan` then `eks-harness score render`; otherwise `eks-harness video validate` then `eks-harness video render`. Extract a few frames at cue points, Read them, and report the output path and studio link.
